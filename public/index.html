    Forgot password?

    There's no email reset — reset it from the panel host (prints a temporary password if you omit one):

    docker compose exec app node scripts/reset-admin.js you@example.com

    Access is restricted to localhost and your Tailscale network.

    Upload SSH key

    Heads up: web upload sends your private key through the browser. The recommended way to add a key is to place it directly in the keys folder on the host, or transfer it over SFTP. Only upload here if you can't reach the host directly.
